# 🌐 Sahil Kaingade - Portfolio Website

A modern, responsive, and interactive portfolio website built with **React.js**, **Tailwind CSS**, **Node.js**, **Express.js**, and **MongoDB**. It showcases my skills, projects, education, experience, and includes a contact form integrated with MongoDB.

---

## 🚀 Live Demo

**Portfolio:**  
👉 https://sahilkaingade.vercel.app/

---

## ✨ Features

- 📱 Fully Responsive Design
- 🎨 Modern UI with Tailwind CSS
- ⚛️ React Component-Based Architecture
- 👨‍💻 About Me Section
- 💼 Skills Showcase
- 🚀 Projects Portfolio
- 🎓 Education Timeline
- 💻 Experience Section
- 📄 Resume Download
- 📬 Contact Form with MongoDB Integration
- ⚡ Fast Performance
- 🌙 Clean and Professional Design

## ⚙️ Installation

### 1. Navigate to the Project Folder

```bash
cd portfolio
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npm start
```

The application will run at:

```
http://localhost:3000
```
